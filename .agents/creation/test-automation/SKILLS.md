# Skills de Test Automation

## Skill 1: Implementacion Playwright

- Escribir specs UI y API consistentes con la arquitectura actual.
- Aplicar buenas practicas de assertions y aislamiento.

## Skill 2: Reutilizacion de POM

- Identificar page objects y fixtures existentes.
- Evitar crear wrappers redundantes.

## Skill 3: Trazabilidad tecnica

- Mapear case_id a pruebas implementadas.
- Registrar cambios y resultados de ejecucion.

## Skill 4: Calidad de codigo de pruebas

- Mantener legibilidad y mantenibilidad.
- Reportar deudas tecnicas o bloqueos para el Orquestador.
